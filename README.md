# 手描きマーカー — SYNC_DrawMarker

AviUtl2 の解説動画で、映像上のボタンや文字を囲んだり、経路をなぞって示したりする Win64 プラグインです。

## 使い方

1. AviUtl ExEdit2 **v2.1.18b 以降**で、映像の上にフィルタオブジェクトとして「手描きマーカー」を追加します。画像・動画オブジェクトにフィルタ効果として追加することもできます。
2. 対象区間内で再生を停止し、設定欄の **描画を編集** を押します。クリック時点のフィルター入力が、編集ウィンドウの背景になります。
3. 初期モードは **選択** です。左側のアイコンにカーソルを重ねるとツール名が表示されます。**連続線** はクリック（ペンではタップ）で頂点を置き、終点をほぼ同じ位置でダブルクリックして確定します。Enter でも確定できます。**自由線** はマウスのドラッグまたは Windows Ink 対応ペンで描き、ボタンやペンを離すと確定します。
4. **選択** では空いている場所からドラッグすると、範囲にかかった線をまとめて選択できます。線を直接ドラッグすると一画を移動できます。連続線の頂点を直接選択でき、右クリックの **削除** でその頂点を削除できます。連続線の頂点の間を右クリックして **頂点を追加** を選ぶか、Ctrl+クリックすると曲線上に頂点を追加できます。**編集** メニューで元に戻す（Ctrl+Z）、やり直す（Ctrl+Y または Ctrl+Shift+Z）、削除（Delete）、頂点の種類の切り替え（Ctrl+T）ができます。
5. 上部のツールバーで **ペン・太さ・先端・回転** を設定できます。ペンは通常・マーカー・発光・破線・筆ペン・チョーク・鉛筆・クレヨンから選べます。先端は丸・四角・三角・長方形で、長方形は回転 0° で横長、90° で縦長です。右側のカラーピッカーで色を、その下のスライダーで **透明度** を調整できます。標準値は 0% で、100% では線が見えなくなります。スライダーにカーソルを重ねてホイールを回すと、太さは 1 px、回転は 1°、透明度は 1% ずつ変わります。色コード欄では `#RRGGBB` や `R,G,B` を入力できます。複数の線を選ぶと一番手前の線の設定が表示され、変更した項目が選択中のすべての線に反映されます。描画モードに切り替えると、表示していた設定が新しい線にも引き継がれます。自由線をペンで描くと筆圧に応じて線幅が変わり、鉛筆では濃さも変わります。マウスの自由線と連続線は設定した太さで描画します。
6. 編集ウィンドウを閉じると、描画内容をオブジェクトへ保存します。設定欄の **描画データ** で保存された JSON を確認できます。描画の変更は **描画を編集** から行います。

描画速度の初期値は **100.00**。50.00 で半分、200.00 で2倍、400.00 で4倍です。自由線は記録した経過時間、連続線は曲線長に沿って進みます。複数の一画は作成順に描かれます。描き終わった線はオブジェクトの末尾まで表示されます。

フィルタオブジェクトとして追加すると、描画領域はその場で合成された下位レイヤーの入力サイズです。素材にフィルタ効果として追加すると、その素材の画像座標を使い、配置・拡大率・透明度は素材の標準描画設定に従います。
